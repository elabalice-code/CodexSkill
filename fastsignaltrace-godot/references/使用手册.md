# fastsignaltrace-godot 使用手册

`fastsignaltrace-godot.exe` 是 FastTool 系列的 Godot/GDScript 静态信号追踪 CLI。它递归扫描指定根目录中的 `.gd` 文件，识别脚本级与嵌套类成员的生产/消费角色，并为 `if/elif/else` 和 `match` 控制域生成标准方程。

## 快速使用

```powershell
fastsignaltrace-godot.exe "D:\Work\MyGodotProject" `
  --output ".\equations.txt" `
  --variables-output ".\variables.tsv" `
  --verbose
```

未指定 `--output` 时，标准方程逐行写入标准输出，诊断信息只写入标准错误。

## 标准方程

```text
Core_Player_gd_42:Player.input_enabled+Player.speed=Player.velocity
```

方程域名由相对源码路径与控制结构起始行组成；路径分隔符、空格和点统一替换为下划线。输入包括赋值右侧读取的脚本成员，以及控制该写入的条件成员。同一控制域对同一输出的依赖会合并并稳定排序。

## 信号范围与角色

- 扫描 `var`、`const`、`static var`、`@export var`、`@onready var` 等脚本/类成员。
- 排除 `func`、属性 `set/get` 体内声明的局部变量和参数。
- `Producer` 表示被读取，`Consumer` 表示被写入，二者兼具为 `Producer+Consumer`，无显式访问为 `Unused`。
- 成员初始化计为一次写入；集合的已知变更方法按读写处理。

`--variables-output` 生成 UTF-8 TSV：

```text
Signal	Role	ReadCount	WriteCount	Declaration
Player.velocity	Producer+Consumer	2	1	Core/Player.gd:8
```

## 命令行与退出码

```text
fastsignaltrace-godot.exe <源代码根目录> [选项]
-o, --output <文件>
    --variables-output <文件>
    --exclude <目录名>
-v, --verbose
-h, --help
    --version
```

| 退出码 | 含义 |
| ---: | --- |
| 0 | 扫描成功 |
| 2 | 参数错误或根目录不存在 |
| 3 | 没有找到 `.gd` 文件 |
| 4 | 分析发生未处理错误 |

## 静态分析边界

本工具使用依赖无关、缩进感知的 GDScript 词法分析，不执行 Godot 工程。动态属性名、字符串形式的 `get/set`、运行时脚本加载、反射和跨函数返回值传播不能完整还原。无显式输入的常量写入不会伪造方程。

## 发布信息

Windows x64、.NET 8 自包含单文件发布。`release` 目录只保留 `fastsignaltrace-godot.exe` 与本手册，目标设备无需另带 DLL 或预装 .NET。
