# fastsignaltrace-rusttauri 使用手册

`fastsignaltrace-rusttauri.exe` 是 FastTool 系列的 Rust+Tauri 静态信号追踪 CLI。它在同一个工程根目录内扫描 Rust 后端的 `.rs` 文件，以及 Tauri 前端的 `.ts/.tsx` 文件，统一输出生产者、消费者角色和标准方程。

## 快速使用

```powershell
fastsignaltrace-rusttauri.exe "D:\Work\MyTauriProject" `
  --output ".\equations.txt" `
  --variables-output ".\variables.tsv" `
  --verbose
```

未指定 `--output` 时，方程写到标准输出，统计与警告写到标准错误。

## 语言信号范围

Rust：

- 模块级或关联的 `static`、`static mut`、`const`。
- 具名 `struct` 字段，包括私有和 `pub` 字段。
- 排除函数内 `let`、函数参数和函数内局部 `const`。
- 识别普通/复合赋值及常见原子、集合变更方法。

TypeScript/TSX：

- 模块级 `const/let/var` 与具体 `class` 字段。
- Zustand `create<State>` 所绑定状态接口中的数据字段；函数型 action 字段不作为数据信号。
- 排除普通函数、React 组件与 hook 内的局部变量和参数。
- 识别赋值及同一行 `set({ field: value })` 状态写入。

## 标准方程

```text
service_src_state_rs_88:AppState.ready+AppState.source=AppState.result
src_stores_appStore_ts_42:AppStore.online+AppStore.phase=AppStore.label
```

域名使用相对源码路径与 `if/match/switch` 起始行；路径分隔符、空格和点转为下划线。输入由控制条件与写入右侧的全局状态并集组成，同域同输出稳定合并。

## 变量表与角色

```text
Signal	Language	Role	ReadCount	WriteCount	Declaration
AppState.ready	Rust	Producer	2	0	service/src/state.rs:12
AppStore.phase	TypeScript	Producer+Consumer	3	2	src/stores/appStore.ts:8
```

角色为 `Producer`、`Consumer`、`Producer+Consumer`、`Unused`。计数是静态引用计数，不是运行时执行次数。

## 命令行与退出码

```text
fastsignaltrace-rusttauri.exe <源代码根目录> [选项]
-o, --output <文件>
    --variables-output <文件>
    --exclude <目录名>
-v, --verbose
-h, --help
    --version
```

| 退出码 | 含义 |
| ---: | --- |
| 0 | 扫描成功 |
| 2 | 参数错误或根目录不存在 |
| 3 | 没有找到 `.rs/.ts/.tsx` 文件 |
| 4 | 分析发生未处理错误 |

## 静态分析边界

本工具不编译或执行目标工程，使用依赖无关的词法与块结构分析。宏展开、过程宏、复杂 trait/泛型类型推断、解引用别名、跨函数返回值传播、动态对象键、跨行复杂 Zustand `set` 对象和运行时生成代码不能完整还原。对于同名字段无法可靠绑定的情况采用保守的唯一名称规则，不伪造无输入方程。

## 发布信息

Windows x64、.NET 8 自包含单文件发布。`release` 目录只保留 `fastsignaltrace-rusttauri.exe` 和本手册，无需另带 DLL 或预装 .NET。
