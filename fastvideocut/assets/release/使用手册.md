# fastvideocut 使用手册

## 功能

按指定的开始和结束秒数，精确剪辑视频，并在输入文件的同一目录生成 MP4 文件。

## 调用方式

```text
fastvideocut.exe <输入视频> <开始秒数> <结束秒数>
```

示例：

```text
fastvideocut.exe xxx.mp4 43 65
```

输出为：

```text
xxx_43_65.mp4
```

支持小数秒，且必须使用英文句点：

```text
fastvideocut.exe demo.mp4 43.5 65.25
```

## 行为与限制

- 开始秒数必须大于等于 0，结束秒数必须大于开始秒数。
- 为保证切点准确，工具会重新编码视频和音频；它不会只按关键帧复制流。
- 为避免误覆盖，若目标输出文件已存在，工具会终止并返回退出码 `3`。
- 工具为 Windows x64 单文件程序；视频引擎已嵌入 exe，运行时仅在系统临时目录短暂释放，结束后自动清理。
- 成功返回 `0`；调用参数或输入无效返回 `2`；剪辑失败返回视频引擎的非零退出码。

## 第三方组件

本工具内置 FFmpeg 8.1.1 full build（Gyan.dev），用于媒体解码和编码。该构建启用了 GPL 组件，适用 GPLv3；FFmpeg 源码与许可证见 <https://ffmpeg.org/>，该 Windows 构建信息见 <https://www.gyan.dev/ffmpeg/builds/>。
