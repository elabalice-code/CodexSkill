# fastsignaltrace-uefi CLI 参考

```text
fastsignaltrace-uefi.exe <UEFI 根目录> [选项]

-o, --output <文件>              UTF-8 标准方程；省略时写标准输出
    --variables-output <文件>    制表符分隔的角色表
    --exclude <目录名>           追加排除目录名；可重复
-v, --verbose                    统计与警告写标准错误
-h, --help                       帮助
    --version                    版本
```

`variables.tsv` 列为 `Signal / Role / ReadCount / WriteCount / Scope / Declaration`。Scope 包括 `UefiProtocol`、`UefiProtocolMethod`、`UefiPpi`、`UefiPcd`、`UefiHob`、`UefiEvent`、`UefiCallback`、`UefiRuntimeVariable`、`UefiService`、`GlobalState`、`LocalVariable`。

默认排除 `.git/.vs/bin/obj/Build/artifacts/TestResults`。输入解码支持 UTF-8、UTF-16 BOM，以及无 BOM 的 Windows 936 回退。

退出码：`0` 成功，`2` 参数/目录错误，`3` 没有 `.c/.h`，`4` 分析异常。

分析使用容错词法/结构规则。宏展开、编译条件、跨函数复杂别名、动态协议 GUID、运行时事件顺序和完整返回值传播属于静态盲区。
